## 已落实方案

1. 同一模板只描述采集开关和周期；新增可选telemetry及details（依赖telemetry），旧模板/默认保持身份v1。
2. Probe每USB模块实际识别；精确FM160-CN匹配首个内置适配规则，未知型号保留通用ATI/IMEI，不尝试其他厂商专有指令。每轮重识别以适应换模块/USB重枚举；暂不加入身份缓存优化。
3. 固定只读查询和响应前缀，保留独占/占用复核、命令/整轮预算；超时停止链路后续查询，不影响心跳。厂商新增规则随代码/Probe发布，不接受任意AT脚本。
4. 明确v2及details能力和独立EVENT；Gateway严格边界校验，Device Service统一解析，生成器与WPF按能力门禁。原始响应保留可追溯，不让各Client重复解析。
5. 用户要求的5项蜂窝UI调整：自动口不显示选择器、快照原位更新不跳页、仅当前路径与查询字段、右侧RSRP/SINR/RSRQ固定轴三图、移除诊断行和冗余说明。必要空态/占用/过期状态保留。
6. 未知/缺测/255形成空值或曲线断点，图表不伪造0；不同模块/会话/版本/制式不混线。
